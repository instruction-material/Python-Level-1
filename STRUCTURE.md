# Python-Level-1 Structure

This repository backs `Python Level 1`. Historical folder names remain
title-case or compact module names, but each active project now uses the common
wrapper shape.

Active public folders stay at the repository top level and contain
`README.md`, `starter/`, and `solution/`. Folders not linked by the live catalog
on 2026-05-14 were moved to `_archived-unlinked/`.

Some migrated projects have only one real legacy snapshot; the opposite role
folder contains a README placeholder until a distinct starter or solution is
authored.

Do not add unlinked `Starter`, `Solution`, `Updated`, or duplicate-era folders
beside the active course surface. Add new material inside a wrapper and link it
from the course site in the same change.
