# GrS12 Random Number Lists starter

Open `main.py` in Turtle mode. Build three rows from the same list. The first row shows fifteen random integers from 0 to 10. Each value in row two is ten more than the value above it. Each value in row three is ten times the value above it.

Try the fixed list `[0, 4, 10]` first. Expect rows `[0, 4, 10]`, `[10, 14, 20]`, and `[100, 140, 200]`. Run with random values after all three fixed rows match.
